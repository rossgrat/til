# Consume vs Create

This isn't exactly quote, but more a high level idea. It's easy to fall into the trap of consuming too much. Watching movies, playing video games, listening to podcasts, etc. (I'm not putting technical on non-fiction books under consume, because I feel like those sort of actively create new knowledge).

One should strive to balance consumption and creation. Creation is of course learning something new, doing projects, etc.
